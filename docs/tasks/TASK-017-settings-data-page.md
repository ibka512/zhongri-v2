# Task 017：设置与数据安全页入口

## 目标

在首次设置之后提供一个可返回、可解释的“设置与数据”页面，让用户知道当前学习目标、
本地数据状态和旧版迁移入口。页面是本地优先产品的安全说明入口，不把隔离暂存误称为已经迁移。

## 范围内

- 新增 `/settings` 路由和响应式设置与数据页面。
- 读取并展示 Task 016 已保存的 `LearnerSettings`：语言、每日时长、学习重点和声音偏好。
- 通过现有首次设置入口修改目标，不复制另一套设置写入逻辑。
- 复用 `detectLegacyV1Data` 显示“检测到 / 未检测到 / 暂时无法检测”的只读状态。
- 提供返回今日学习、调整学习目标和检查旧版备份的明确入口。
- 明确说明 v2 当前是本地优先、无账号；迁移预检和隔离暂存不会自动改写旧数据。
- 为无设置、检测失败和读取失败提供可恢复的空/错误状态。

## 范围外

- 不新增或修改 `LearnerSettingsSchema` 字段，不实现主题/减少动态/触觉的持久化。
- 不实现备份导出、导入、恢复点、回收站恢复或完全重置；这些能力沿用现有迁移边界，另行授权。
- 不执行迁移验证、激活、回滚或任何 v1 写入。
- 不实现五十音、IPA、TTS、通知、AI、账号、同步或新的主导航体系。

## 影响层

- UI：新增设置与数据页面和样式。
- Application/Composition：只复用已有 `loadUserSettings`、`detectLegacyV1Data` 组合入口。
- Ports/Infrastructure：不新增持久化接口或数据库表。
- 文档：新增 ADR-039，并更新 `PROJECT_CONTEXT.md`、`TASKS.md` 和 `HANDOFF.md`。

## 验收标准

1. 已完成首次设置的用户打开 `/settings` 能看到与本地记录一致的语言、时长、重点和声音状态。
2. 没有设置记录时，页面说明需要先完成首次设置，并提供可达的入口；不显示伪造的默认已保存状态。
3. v1 来源检测分别呈现检测到、未检测到和暂时无法检测；检测失败不阻断页面其他入口。
4. 返回今日学习、调整学习目标和检查旧版备份均为键盘可达的语义链接或按钮。
5. 页面不直接访问 Dexie、IndexedDB、LocalStorage 或迁移写入用例。
6. 新增 UI/Application 测试覆盖已设置、无设置、检测失败和入口导航；`npm run verify` 全部通过。
