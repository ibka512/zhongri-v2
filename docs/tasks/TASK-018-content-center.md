# Task 018：内容中心首个只读切片

## 目标

在今日学习和设置与数据之间提供一个可达的“内容中心”，让用户能确认当前语言使用的
canonical 词库规模、版本与来源，并浏览一小段真实词条。这个切片先建立双语内容入口，
不把词库浏览误称为用户词库管理或学习进度管理。

## 范围内

- 新增 `/content` 路由和响应式内容中心页面。
- 读取 Task 015 已通过完整性门禁的 `CanonicalContentRepositoryPort`，展示当前语言的词条总数、内容版本和来源摘要。
- 按当前本地 `LearnerSettings.language` 展示日语或英语内容；无设置时沿用今日课程的日语默认值。
- 支持按词形、读音/音标、释义的本地即时搜索，以及按 level 筛选。
- 结果列表最多展示前 50 条，并明确剩余匹配数量，避免一次性渲染完整 5,906/3,922 条词库。
- 为加载中、读取失败、无结果和无设置提供可解释且可恢复的状态。
- 提供返回今日学习、设置与数据和调整学习目标的深链接。

## 范围外

- 不新增内容 Schema、数据库表、用户词或内置词覆盖。
- 不实现编辑、收藏、错题、掌握状态、导入/导出、批量操作或虚拟化网格。
- 不实现五十音、IPA、TTS、音频缓存、通知、AI、账号或同步。
- 不复制一套新的语言设置写入逻辑；切换语言统一回到 `/onboarding`。
- 不改变 canonical corpus 的顺序、ID、来源或完整性门禁。

## 影响层

- UI：新增内容中心页面、筛选控件、只读词条卡片和响应式样式。
- Application/Composition：新增 `loadCanonicalContent` composition callback，页面不直接加载资产文件或读取浏览器存储。
- Ports/Infrastructure：复用既有 `CanonicalContentRepositoryPort` 与完整性校验，不新增持久化能力。
- 文档：新增 ADR-040，并更新 `PROJECT_CONTEXT.md`、`TASKS.md`、`STATUS.md` 和 `HANDOFF.md`。

## 验收标准

1. 已设置日语或英语的用户打开 `/content`，看到对应语言的词库数量、内容版本、来源摘要和词条列表。
2. 没有设置时页面仍可读，明确使用日语默认内容，并提供进入首次设置的入口；不伪造已保存目标。
3. 搜索同时匹配当前语言词条的词形、reading/phonetic 与 meaning；level 筛选可组合使用。
4. 搜索无结果时显示原因和清除筛选的恢复动作；匹配超过 50 条时明确提示当前展示上限。
5. 内容加载失败时显示错误和重试入口；页面不直接访问 Dexie、IndexedDB、LocalStorage 或网络。
6. 结果卡片语义化、键盘可达、移动端无横向滚动，且不使用颜色作为唯一信息。
7. 新增 UI/路由测试；`npm run verify` 全部通过。
