# ADR-038：以本地 UserSettings 契约承载 Phase 1 首次设置

## 状态

已接受（2026-07-27，Phase 1 产品收口首个切片）

## 背景

Task 015 的迁移与负责人真实 v1 数据手工验收已经完成。下一步需要补上 MVP 用户闭环的
“第一次打开”和“设置目标”：用户必须在进入今日课程前选择语言、每日时长、学习重点和声音偏好。
当前仓库只有今日课程技术切片，没有持久化的本地学习者设置，也没有首次打开入口。

## 决策

- 新增版本化 `LearnerSettingsSchema v1`，只保存本地学习者设置，不把它当作云账号。
- 首次设置的最小字段为 `language`、`dailyMinutes (5|10|15)`、`focus`、`audioEnabled`、
  `setupCompleted` 和 `updatedAt`；设置通过 Repository Port 写入 v2 Dexie 数据库。
- 首次打开由启动路由读取设置：没有已完成设置时进入 `/onboarding`，保存成功后再进入 `/today`；
  已有设置的用户仍可从今日页进入 `/onboarding` 修改目标。
- v1 数据检测只读复用既有 `BrowserV1SourceStorage`，只呈现“检测到 / 未检测到 / 暂时无法检测”
  的状态，不在首次设置流程中执行迁移或写入 v1 存储。
- 首次设置不接入 AI、TTS、通知或账号；声音开关只记录偏好，音频能力由后续独立切片实现。

## 验收标准

1. 全新浏览器打开根路由会进入首次设置；语言、时长、重点和声音均有可见默认值且可修改。
2. 未选择必要选项时不能提交；保存失败时保留用户选择并提供重试。
3. 保存后刷新根路由仍进入今日课程；再次进入 `/onboarding` 会预填当前设置。
4. v1 来源检测失败不阻断首次设置，并明确提示可稍后在设置与数据页继续处理。
5. InMemory 与 Dexie 设置 Repository 通过同一契约测试，`npm run verify` 全部通过。

## 不在本 ADR 范围内

- 今日计划根据时长和重点动态调整；本切片只建立可读取的设置事实。现有每日课程会读取语言和目标
  时长，避免用户选择英语后仍看到日语入口；重点对队列的完整影响留给后续切片。
- 设置与数据页、备份/恢复 UI、五十音、IPA、TTS 和 AI Gateway。
- 任何真实 v1 数据写入或迁移激活。
