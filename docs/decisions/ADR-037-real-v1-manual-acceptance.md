# ADR-037：以负责人真实 v1 数据手工验收关闭迁移阻塞

## 状态

已接受（2026-07-27，负责人反馈真实 v1 数据测试无问题）

## 背景

此前仓库只保留 synthetic fixture，无法确认真实 v1 备份在托管预览中的实际使用体验。负责人已在
GitHub Pages 预览站使用真实 v1 数据完成测试，并反馈没有发现问题。真实备份包含私人学习数据，
不应上传到仓库或提交到 GitHub。

## 决策

将本次结果记录为“真实数据手工验收通过，原始数据不入库”：

- 负责人负责真实数据的选择、上传和结果观察；仓库只记录验收结论，不保存备份文本、报告中的私人
  内容或任何 API Key；
- 该结论关闭 Task 015 的真实使用阻塞，允许项目进入 Phase 1 产品功能收尾；
- synthetic V01–V25、activation 和 rollback 自动验收继续作为可重复的工程证据；真实数据手工验收
  作为产品使用证据，不伪造或回填不可审计的真实 report digest；
- 如果未来需要合规审计，应由负责人在本地重新导出脱敏报告并单独保存，不把原始备份提交到代码仓库。

## 影响

- Task 015 的迁移流程可标记为“负责人真实数据手工验收通过”。
- 当前项目下一步转向首次设置、内容中心、设置/数据安全和双语内容切片；AI Gateway 仍需等 Phase 1
  完整验收后再开始。
- 真实数据已通过本次手工验收不代表仓库获得该数据的保留或同步权限。
