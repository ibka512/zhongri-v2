# 产品范围索引

## 定位

钟日 v2 是面向中文母语者的 AI 个性化语言学习伙伴，当前主要支持日语和英语。

## 当前 MVP 原则

- 首页方向是今日学习计划，而不是多个旧学习模式入口。
- MVP 答题原语只有选择和文本输入，音频作为组合能力。
- 固定答案由程序判断；开放回答和语音回答不属于当前实现范围。
- AI 负责未来的计划建议、结构化内容生成和解释，不负责 UI 或学习事实。
- 基础路径在离线、AI 不可用或额度不可用时仍应成立。

## 当前实现状态

仓库已有可恢复的三题学习技术演示、单会话安全重开，以及 v1 JSON 备份的只读迁移预检。
通过预检的备份还可由用户明确写入脱敏隔离数据集，但不会转换或激活业务数据。这些能力用于
